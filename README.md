# Spielautomat wie in den 80ern

**Nur Spielgeld, kein echtes Glücksspiel.**

Zwei Wandgeräte wie früher in der Kneipe: ein Walzen-Automat und ein Scheiben-Automat.
Mit Risikoleiter, Ausspielung, Sonderspielen, Startautomatik und Teilen-Taste.
Gespielt wird nur mit Spielgeld in D-Mark. Man kann nichts kaufen und nichts gewinnen.

**Direkt spielen:** https://zoomfaktor.github.io/spielautomat/
(läuft im Browser, am PC und am Handy, ohne Anmeldung)

Gebaut von jemandem, der nicht programmieren kann, zusammen mit der KI Claude Code.
Mehr dazu auf dem YouTube-Kanal **Zoomfaktor**.

Auf Dauer zahlen solche Automaten weniger aus, als man hineinsteckt. So waren sie gebaut.
Darum hier nur Spielgeld.
